# Breast Cancer Detection

Predicts whether a tumour is malignant or benign using two models and compares them.

- **Dataset:** Breast Cancer Wisconsin (from scikit-learn)
- **Models:** Logistic Regression and K-Nearest Neighbors
- **Results:**
  - Logistic Regression accuracy: 95.6%
  - KNN accuracy: 95.6%
- **Conclusion:** Both models performed equally well on this dataset.

## How to run
Open `Breast_cancer.ipynb` in Google Colab and click Run all.
